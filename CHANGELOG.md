# Журнал изменений

Все значимые изменения проекта Lab100. Схема версий — «основная.младшая»
(без третьего компонента), git-теги с префиксом `v`. Текущая версия пакета —
`lab100.__version__` в `lab100/__init__.py`.

Формат записи — по [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
семантическое версионирование.

## [0.5.1] — не выпущено

### Добавлено

- Непрерывная проверка тестов: GitHub Actions (`.github/workflows/tests.yml`) —
  прогон на Python 3.10/3.11/3.12 при push в `main` и при pull request в `main`.
- Диагностика пула провайдеров в логе CI: `python -m lab100.cli providers`
  показывает, какие адаптеры поднялись, а какие отключены и почему.
- Этот журнал изменений (`CHANGELOG.md`).
- В README: раздел о непрерывной проверке и строка про workflow в дереве
  структуры репозитория.

### Известные ограничения

- `tests/test_pool.py::test_config_has_case1_local_providers` падает, пока в
  секретах репозитория нет `FIRECRAWL_API_KEY`: без ключа провайдер `firecrawl`
  не попадает в пул. Падение намеренно не скрывается и не подменяется
  фиктивным прохождением. Локальный прогон без ключей: 46 тестов, 44 прошли,
  2 упали; в CI на 3.11/3.12 — 45 из 46 проходят, падает тот же тест.
- Расхождение заявленной версии Python: `pyproject.toml` объявляет
  `requires-python >=3.10` и классификатор 3.10, но код импортирует `tomllib`,
  а он есть в стандартной библиотеке только с Python 3.11. Поэтому на 3.10
  в CI падают 9 тестов с `ModuleNotFoundError: No module named 'tomllib'`.
  Фактический минимум проекта — Python 3.11. Расхождение не скрывается: нужно
  либо сузить `requires-python` до `>=3.11` и убрать классификатор 3.10, либо
  обеспечить импорт `tomllib` через `tomli` на 3.10. Решение за владельцем.

## [0.5.0] — 2026-09-27 (тег `v0.5.0`)

### Добавлено

- Адаптер Yandex Search API (`yandex-search`): веб-поиск по базе Яндекса
  (REST v2, разбор выдачи `rawData` = base64/XML). Только компетенция
  `web-search`, без скрейпинга. Платный: приоритет 15 (последний в каскаде),
  месячный предохранитель 500 запросов. Ключ — `YANDEX_SEARCH_API_KEY` или
  `YANDEX_SEARCH_IAM_TOKEN`, `folderId` — `YANDEX_SEARCH_FOLDER_ID`.
- Устанавливаемый пакет: `pyproject.toml` (setuptools), лицензия MIT,
  точка входа `lab100 = lab100.cli:main`.
- Поиск конфига вне рабочего каталога: кроме `config/agents.toml` читаются
  `%LOCALAPPDATA%\lab100\agents.toml` и `%APPDATA%\lab100\agents.toml`, чтобы
  настройки находились и для установленного пакета.

## [0.4.1] — 2026-09-26

### Добавлено

- Канал `docker-cloud`: облачные модели через docker agent, дефолт
  `groq/llama-3.3-70b-versatile` (бесплатный rate-limit tier). Docker-каталог
  поддерживает и платные провайдеры.
- Фабрика адаптеров `docker-*` и тест на неё.

### Исправлено

- `local-browser`: `DRIVER_DIR` указывает на постоянный каталог
  `C:\Scripts\tools\browsertool`.

## [0.3.2] — 2026-09-21

### Добавлено

- Адаптер `docker-agent` (Гордон) в пул: бесплатный локальный LLM через Docker
  Model Runner, плюс 3 теста.
- `__version__` синхронизирован с версией релиза.

### Изменено

- Тест `local-browser` толерантен к отсутствию node-драйвера.
- Тест `docker-agent.init()` приведён к актуальной логике: проверка плагина по
  файлу, без `subprocess`.

## [0.3.1] — 2026-09-20 (тег `v0.3.1`)

### Добавлено

- Провайдер Gemini: модель `gemini-3.6-flash`, ключ `GEMINI_API_KEY`, квота
  150 000 токенов/день. Подключается автоматически при наличии ключа.
- Тест каскада поиска.

### Изменено

- Каскад поиска при 403/блокировке провайдера: пул переходит на следующего
  кандидата, не падая.
- README: описание ограничений сети и архитектуры пула.

## [0.3.0] — 2026-09-20 (тег `v0.3.0`)

### Добавлено

- Провайдер Exa: семантический веб-поиск `/search` (с highlights) и
  `/contents`, ключ `EXA_API_KEY`, приоритет 45 (ниже Firecrawl).

## [0.2.2] — 2026-09-20 (тег `v0.2.2`)

### Добавлено

- Локальные веб-агенты «Кейса 1» с нулевым расходом кредитов:
  - `local-browser` — поиск и скрейпинг через headless Edge/Chrome
    (драйвер `driver.mjs`, `127.0.0.1:8123`), движки `wiby`, `bing`,
    `duckduckgo`, `wikipedia`; драйвер поднимается автоматически при наличии
    `node.exe`.
  - `plain-http` — самый лёгкий адаптер: поиск по Bing-HTML (URL из
    редиректов декодируются) и скрейпинг статических страниц без браузера.
- Авто-фоллбэк на локальные агенты при исчерпании Firecrawl.

## [0.2.1] — 2026-09-19 (тег `v0.2.1`)

### Добавлено

- Второй локальный LLM `ollama-8b` (`hermes3:8b`) как резерв: включается по
  запросу (`--llm ollama-8b`) или автоматически, когда 3b в cooldown.
- Принудительный выбор провайдера флагами `--llm` и `--search`.

## [0.2.0] — 2026-09-19

### Добавлено

- Рабочий пул агентов: Firecrawl (веб-поиск и скрейпинг) + Ollama (локальный
  LLM).
- Учёт квот (кредиты/токены, окна пополнения, cooldown, reserve).
- Fallback-каскад роутера: при 429, 403 или сетевой ошибке пул переходит на
  следующего кандидата по приоритету.
- CLI: `status`, `providers`, `search`, `ask`, `chat`, `scrape`.

## [0.1.0] — 2026-09-19

### Добавлено

- Каркас пула бесплатных ИИ-агентов: резюме исследования, реестр агентов по
  компетенциям, базовые интерфейсы адаптеров.
