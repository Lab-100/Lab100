# Анализ кейсов: бесплатные ИИ-агенты веб-поиска

Дата анализа: 19.09.2026.
Цель — выбор стеков под автономный веб-поиск/выполнение поручений по промпту
без (или с минимальной) оплатой.

## Кейс 1. Полностью бесплатный стек (офлайн/локальный)

Суть: открытый исходный код + локальная модель. Всё работает на своём железе.

| Компонент | Инструмент | Примечания |
|---|---|---|
| Браузерный агент | **WebBrain** (MIT) | расширение Firefox/Chrome, понимает нат. язык, кликает, заполняет формы, извлекает данные; Act Mode = полноценный агент |
| Альтернатива CLI | **browserbash-cli** | управляет реальным Chrome по текстовой инструкции через Ollama |
| Локальные модели | **Ollama** (Llama, Qwen, Gemma, Mistral) | ноль затрат, приватность, нужен мощный ПК/GPU |
| Локальный веб-агент | **Hound (hound-mcp)** | MCP-сервер: поиск, загрузка страниц, обход блокировок, чтение PDF; без ключей |
| Облачный движок (опц.) | **Cloudflare Kitesurf** | бета, бесплатно; лёгкий веб без видео/WebGL/капч |

Итог кейса 1: WebBrain (или browserbash) + Ollama. Полностью бесплатно, без карты,
без лимитов. Цена — мощности и время локальной машины.

## Кейс 2. Стек с бесплатным ограниченным доступом (облако)

Суть: облачные сервисы с бесплатным тиром — кредиты/запросы в день/месяц.

### Браузерная инфраструктура (бесплатные тиры)

| Сервис | Бесплатный лимит |
|---|---|
| Browserbase | 1 сессия + 60 мин браузерного времени/мес |
| Hyperbrowser | 1 000 кредитов + 1 параллельный браузер |
| Notte | $10 кредитов разово (без срока действия) |
| Axiom.ai | 2 часа рантайма/мес (без карты) |
| Coasty | 10 мин агентского времени/мес |

### LLM-провайдеры с бесплатной квотой

| Провайдер | Лимит | Модели |
|---|---|---|
| Google Gemini | ~1 500 req/день | 2.5 Flash / 3.6 Flash |
| Groq | 1 000 req/день (30 RPM) | Llama 3.3 70B |
| Kimi (Moonshot) | 1 000 вызовов/мес (ctx 256K) | Kimi K2.5 |
| Cerebras | 1 млн токенов/день | Llama, Qwen |
| Cloudflare Workers AI | 10K нейронов/день | Llama 70B, Gemma 3 |
| Qwen (Alibaba) | 1 млн токенов (90 дней) | Qwen3 235B |
| Pollinations | без ключа | GPT-5, Claude, DeepSeek |
| NVIDIA NIM | 40 RPM навсегда | 70+ open-моделей |

Предупреждение: лимиты меняются; перед продакшеном сверять условия на сайтах
провайдеров.

## Итоговая рекомендация

- Кейс 2 — основной для пула агентов: много независимых бесплатных квот.
- Для реальной работы квота может исчерпаться в середине задачи → нужен менеджер
  пула (см. architecture.md), который следит за остатком и переключает провайдера.
