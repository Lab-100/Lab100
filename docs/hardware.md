# Требования к локальному компьютеру

## Вариант 1: только облачные API (кейс 2)

Менеджер пула только распределяет задачи; модели работают на серверах провайдеров.
Компьютер — тонкий клиент.

| Компонент | Рекомендация |
|---|---|
| CPU | 4–6 ядер (Intel i5 / Ryzen 5) |
| RAM | 16 ГБ (8 ГБ — тесно при браузере + агентах) |
| SSD | 20–50 ГБ свободного места |
| GPU | не требуется |

Вывод: подходит любой современный офисный ПК/ноутбук.

## Вариант 2: гибрид с локальной моделью (кейс 1 + резерв в кейсе 2)

Локальная LLM (Ollama) — узкое место видеоим

| Компонент | Рекомендация |
|---|---|
| CPU | 8 ядер (i7 / Ryzen 7) |
| RAM | 32 ГБ (16 ГБ — минимум) |
| GPU | см. ниже |
| SSD | 100+ ГБ (модели 5–20+ ГБ каждая) |

### GPU по задачам

| VRAM | Что тянет |
|---|---|
| 8–12 ГБ | 7B–14B модели (Llama 3.1 8B, Phi-4 14B) — низкие/средние настройки |
| 16–24 ГБ | 27B–24B (Gemma 3 27B, Mistral Small 24B) — хорошая логика/инструменты |

### Apple Silicon

M4 Pro/Max или M3 Max с 32+ ГБ unified memory (часть памяти работает как VRAM).

## Вариант 3: распределённый пул

Несколько слабых машин в локальной сети → **Nvidia PAIR** (бесплатно, mDNS)
объединяет их в единый пул инференса.

## Итог

- Облачный вариант: 16 ГБ RAM + любой SSD — достаточно.
- Гибрид: 32 ГБ RAM + GPU 16–24 ГБ VRAM (или Apple Silicon 32+).
- Несколько ПК: Nvidia PAIR.
